# 💊 InventoryRx (FarmaClick) - Frontend

¡Bienvenido al repositorio **Frontend** de **InventoryRx** (FarmaClick)! Esta es una plataforma web para la gestión eficiente de inventarios en farmacias, diseñada con un enfoque centrado en el usuario (UX/UI) y una arquitectura moderna, reactiva y escalable.

---

## 🚀 Tecnologías Utilizadas

- **Framework:** [Vue 3](https://vuejs.org/) (Single File Components con `<script setup>`)
- **Herramienta de Construcción:** [Vite](https://vitejs.dev/)
- **Gestión de Estado Global:** [Pinia](https://pinia.vuejs.org/)
- **Cliente HTTP:** [Axios](https://axios-http.com/)
- **Enrutamiento:** [Vue Router](https://router.vuejs.org/)
- **Estilos / UI:** CSS3 / HTML5 (Sistemas de diseño basados en prototipos de Figma)

---

## ✨ Características Principales

- **Gestión de Inventario:** Visualización, filtrado y control de stock de medicamentos y productos farmacéuticos.
- **Autenticación y Seguridad:** Manejo de sesión de usuario y tokens de acceso (JWT) sincronizados con el backend.
- **Interfaz Intuitiva (UX/UI):** Flujos de navegación optimizados para minimizar el tiempo de operación del personal.
- **Estado Reactivo:** Control centralizado de inventario, carrito/pedidos y datos de usuario mediante Pinia.
